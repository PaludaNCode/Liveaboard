Ten marks for the waterline

Candidate icons for the price–transparency page. Each is a single SVG of a few hundred bytes, drawn on the site’s own palette: accent for what you were quoted, the orange the table reserves for what lands later. None is wired in — pick one and it becomes a data: URI in <head>.

Judged at 16pxA favicon is a tab, a bookmark and a phone shortcut. Every candidate is shown at 64, 32, 24 and 16, and in a tab beside the real page title.
Two colours, both meaning somethingWhere a mark is two-tone it borrows the table’s own semantic rather than inventing one: the berth, and the bill that follows it.
Nothing fetchedOne file, no PNG set, no external host. Each SVG carries its own prefers-color-scheme block, so the dark tile beside every mark is the same file, not a second export.

What shipping one looks like

The page stays one self-contained file, so the mark goes in as a data URI rather than a second request — render.py inlines it the way it already inlines the stylesheet and the data. 

<link rel="icon" href="data:image/svg+xml,<svg xmlns=%27http://www.w3.org/2000/svg%27 viewBox=%270 0 32 32%27>…</svg>">

Say which number and it gets drawn to final, wired into templates/index.html, and covered by the dataset test that keeps ALLOWED_EXTERNAL empty.
